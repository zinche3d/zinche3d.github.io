# Проект

Портфолио playable ads для публикации через GitHub Pages.

## Структура

- `index.html` — лендинг и разметка плеера.
- `styles.css` — адаптивные стили портфолио.
- `script.js` — модальный плеер и смена ориентации.
- `favicon.png` — иконка вкладки браузера 512×512.
- `PlayableAds/` — автономные HTML-игры и исходные превью.
- `PlayableAds/icons/` — квадратные обложки карточек в WebP или JPG.

## Плеер

Игры по умолчанию запускаются в портретном размере 1080×1920.
После поворота используется горизонтальный размер 1920×1080.
Фрейм масштабируется под доступную область без изменения пропорций.
Модальное окно закрывается только кнопкой-крестиком.
Игра имеет белую закруглённую рамку поверх затемнённого лендинга.
Круглая кнопка поворота находится на левом верхнем углу рамки,
крестик — на правом верхнем углу.
Название игры и разрешение в модальном окне не отображаются.

## Контакты

В шапке находятся квадратные кнопки почты и Telegram.

Название портфолио использует стиль названий карточек и белый цвет.

## Добавление работы

Добавить HTML в `PlayableAds/`, затем создать карточку в `index.html`.
Для карточки добавить квадратную обложку 512×512 в `PlayableAds/icons/`.
Имена и регистр файлов должны совпадать со ссылками в `index.html`.
Карточки не должны смещаться при наведении, чтобы избежать мерцания
на границе курсора.

## Проверка

Запустить локальный HTTP-сервер в корне репозитория и открыть
`index.html`. Проверить карточки, обе ориентации и полноэкранный режим.

Команда предпросмотра: `python -m http.server 8000`.
Адрес: `http://127.0.0.1:8000/`.
